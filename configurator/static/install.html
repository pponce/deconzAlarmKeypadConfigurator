About setup and your data

Setup verifies your gateway and optional local Homebridge integration before installing the services. API keys and passwords stay on this server. The browser setup server runs without root privileges; the installer accepts only answers to its current configuration question.

Nothing in this flow tests an alarm or keypad command. If setup is interrupted, retain its local receipts and use the same pinned installer. An uncertain key creation is never repeated automatically.
